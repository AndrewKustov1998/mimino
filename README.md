# Mimino

Багатосторінковий сайт ресторанно-готельного комплексу «Mimino»: головна сторінка,
сторінка ресторану, сторінка готелю та сторінка окремого номеру. Статичний сайт
без бекенду — верстка, стилі та інтерактив на клієнті.

## Технології

- **[Parcel 2](https://parceljs.org/)** — збірник і dev-сервер (нульова конфігурація,
  hot-reload у режимі розробки).
- **SCSS** (`@parcel/transformer-sass`) — препроцесор стилів.
- **[posthtml-include](https://github.com/posthtml/posthtml-include)** — підключення
  HTML-партиалів через кастомний тег `<include src="...">`, оскільки чистий HTML не
  підтримує компонентність.
- **Vanilla JS** — без фреймворків і збірних бібліотек; вся логіка (слайдери, модалки,
  маска телефону) написана на чистому JavaScript.
- **GitHub Actions** — автоматичний білд і деплой на GitHub Pages (гілка `gh-pages`)
  при кожному push у `main` (`.github/workflows/deploy.yml`).

## Структура проєкту

```
src/
  index.html, hotel-page.html, restaurant-page.html, room-page.html   — точки входу
  partials/
    header.html, footer.html, modal.html                              — спільні частини
    home-page/, hotel-page/, restaurant-page/, room-page/              — партиали конкретних сторінок
  sass/
    base/       — reset, глобальні базові стилі
    utils/      — змінні, шрифти
    layout/     — переспільні layout-блоки (контейнер, слайдер, модалка, кнопки)
    components/ — стилі, згруповані по сторінках (home-page/, hotel-page/, ...)
  script.js     — рушій слайдерів (drag/touch/стрілки)
  js/modal.js   — відкриття/закриття модалок, маска телефону
  images/, fonts/
```

Кожна сторінка (`index.html` тощо) — це "скелет", що збирає партиали через
`<include src="./partials/...">`. Стилі кожної сторінки підключаються окремим
`.scss`-файлом (наприклад, `sass/index.scss` для `index.html`), який імпортує
спільні base/utils/layout та компоненти потрібної сторінки.

## Патерни та підходи

- **Партиали замість дублювання розмітки.** Кожна секція сторінки — окремий
  `.html`-файл у `src/partials/`, підключений через `<include>`. Це дозволяє
  перевикористовувати `header`/`footer`/`modal` на всіх сторінках.
- **БЕМ-подібне іменування класів** у SCSS (`блок__елемент--модифікатор`), стилі
  розбиті по файлах-партиалах і згруповані за сторінками в `sass/components/`.
- **Адаптивні зображення** через `<picture>`/`<source>` з `media`-запитами під
  мобільний/планшетний/десктопний брейкпоінти та `1x`/`2x` варіантами для Retina.
- **Уніфікований компонент слайдера.** Один шаблон розмітки
  (`.slider` → `.slider-list` → `.slider-track` → `.slide` × N + `.slider-arrows`)
  та один JS-контролер (`script.js`), який ініціалізується окремо для кожного
  `.slider` на сторінці (`document.querySelectorAll('.slider').forEach(...)`),
  підтримуючи як клік по стрілках, так і drag/touch-свайп.
- **Модалки через `data-`атрибути.** Кнопка з `data-modal="N"` відкриває модалку
  з таким самим `data-modal="N"`; логіка — в `js/modal.js`.
- **Маска вводу телефону** у формах бронювання: поле форматується як
  `+38 (___) ___-__-__` прямо під час набору цифр.

## Розробка

```bash
npm install       # встановити залежності
npm start         # dev-сервер з hot-reload на http://localhost:1234
npm run build     # продакшн-збірка у папку dist/
```

## Деплой

Продакшн-версія автоматично збирається та публікується на GitHub Pages (гілка
`gh-pages`) при кожному push у `main` — див. `.github/workflows/deploy.yml`.
